Question:-Cold Observable

Lazy: Starts producing values only when someone subscribes.

Independent streams: Each subscriber gets its own separate set of values.

Use case: HTTP requests, API calls, anything where each subscriber should get fresh data.


Hot Observable

Eager: Starts producing values immediately, regardless of subscribers.

Shared stream: All subscribers get values from the same ongoing execution.

Use case: Mouse movements, WebSocket events, live data streams.

Question:-What are the outputs when calling f1(), f2(), and f1() after 
initializing var f1 = new fn1(); var f2 = new fn1(); in a factory pattern that generates unique IDs starting from 10?
Answer:-function fn1() { // Outer function acting as a factory
  let x = 10; // Local variable initialized to 10
  return function() { // Return a closure
    return ++x; // Increment and return x
  }
}

var f1 = new fn1(); // Create first closure, x starts at 10
var f2 = new fn1(); // Create second closure, x starts at 10

console.log(f1()); // 11, f1's x goes from 10 to 11
console.log(f2()); // 11, f2's x goes from 10 to 11 (separate from f1)
console.log(f1()); // 12, f1's x goes from 11 to 12

Question:-What are JavaScript promise utility functions
Answer:-
Promise.all():-Run all Promise in parallel wait for all promise complete.If one fail->entire fail.
const p1=Promise.resolve(10)
const p2=Promise.resolve(20)
const p3=Promise.resolve(30)

Promise.all([p1.p2,p3]).then(res=>console.log(res))

Promise.allSettled:-Run all Promise in parallel.wait for all promise success/failure.

Promise.race():-Return first settle promise resolve/reject
const p1 = new promise(resolve=>setTimeOut(()=>resolve('p1'),1000))
const p2=new promise(resolve=>setTimeOut(()=>reject('p2'),500))
Promise.race([p1,p2]).then(result=>{
  console.log(result) //p2
})

promise.any():-Return first successful promise.ignore reject
const p1=Promise.reject('p1')
const p2=Promise.reject('p2')
const p3=Promise.resolve('p3')
Promise.all([p1,p2,p3]).then(res=>console.log(res)) //p3

Promise.resolve():-immediately resolve
Promise.reject():-immediately reject.
